# Bitcoin Breakout Robustness

The archived v5.6 research examined how breakout evaluation changes across entry lookbacks, exit lookbacks, ATR stops, time windows and cost assumptions. The study varied one parameter axis at a time and considered the full archived grid. One-axis variation leaves parameter interactions weakly tested. Both windows were previously reviewed, so repeated model selection can overfit them. Independent holdout evidence is unavailable.

The distribution, subgroup summaries and performance claims from the archive are held for redistribution review. [Research limitations](../../docs/RESEARCH_LIMITATIONS.md)
