# 퀀트 리서치 포트폴리오 요약

해외 주식·ETF 백테스트에서 진입 이전의 가격이 청산에 사용되고 슬리피지가 지정가를 벗어나게 하는 문제를 확인했다. 수정 모형은 진입 이후 경로에서만 청산을 평가하고 지정가 상·하한을 적용한다. 일봉으로 실제 장중 순서나 체결 여부를 확정할 수는 없다. [대표 연구와 합성 도표](../research/execution-model/README.md)

수정 모형의 합성 테스트 21건을 통과했고, 별도의 비공개 동결 입력 검증에서 두 단기 구간의 비교 24건을 재현했다. 기존 40개 시나리오는 원본 산출물 대사 범위다. 과거 v5.3의 수익률 재현은 실패했으며, 생존편향·독립 표본 외 평가·수정 모형의 전체 기간 검증은 미해결이다. 시장 데이터 집계치와 파생 도표는 권한 확인을 기다리고 있다.

ChatGPT와 Codex가 코드 생성, 오류 분석, 수정, 테스트 및 문서에 기여했다. 연구자는 자료와 연구 문제, 검증 범위를 제공했다. [AI 활용](AI_DEVELOPMENT_TRAIL.md) · [재현 방법](REPRODUCIBILITY.md)

합성 반례에서는 진입 전 손절·목표 접촉에 따른 청산이 각각 1건에서 0건으로 줄었다. 매수 지정가 100의 체결가는 100.05에서 100으로, 매도 지정가 109의 체결가는 108.9455에서 109로 바뀌었다. 각 위반 폭은 5bp였으며 수정 모형은 남은 슬리피지를 별도 비용으로 기록한다. [합성 비교표](../results/synthetic_execution_comparison.csv) · [데이터 게시 검토](DATA_PUBLICATION_REVIEW.md)
